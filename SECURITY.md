# Security Policy

## Scope

This project includes a Java mod loading system. A mod JAR can execute code with the permissions of the user running BLOCKWORLD 3D.

## Safe mod use

- Only install mod JAR files from sources you trust.
- Review a mod's source code and requested behavior when possible.
- Keep backups of worlds before testing unfamiliar mods.
- Do not share passwords, access tokens, private save files, or personal data in issues.

## Reporting a security concern

Please do not publish details of an unpatched security issue in a public issue. Contact the repository owner privately through the contact options available on their GitHub profile. Include the affected version, impact, and a minimal reproduction where safe.

This repository does not currently advertise a formal security response-time guarantee.
