# Minecraft 3D — Player Guide

This is a quick reference for the current gameplay systems. Some actions depend on having the required item and selecting a compatible version profile.

## Crystal Caverns & Gem Veins (1.9.5)

- Explore the deeper cave rooms and look for amethyst-lined walls and small underground pools.
- Ruby ore appears in deeper layers; sapphire ore can be found a little higher. Both are rare and need an iron-tier pickaxe.
- The new deposits are generated in newly created 1.9.5 worlds; existing worlds are not regenerated automatically.

## Survival loop

1. Explore the world and gather wood, stone, ores, and food.
2. Use the inventory (**I**) and crafting screen (**C**) to make tools and supplies.
3. Make a hoe and prepare farmland, then plant and harvest wheat.
4. Build a furnace, use fuel and ore to smelt materials, and cook raw fish.
5. Visit villagers to trade selected supplies for emeralds and useful items.
6. Fish near water with a rod, then cook the catch.
7. Open achievements (**M**) to review exploration and gameplay progress.
8. In the 1.1.0 profile, explore taiga and swamp regions, search caves for amethyst veins and underground pools, and meet foxes and turtles. A dog companion follows you around the world.

## Controls

| Key | Action |
| --- | --- |
| Hold left mouse button | Mine the targeted block in survival mode (1.9.4+); releasing cancels progress |
| I | Inventory |
| C | Crafting |
| M | Achievements |
| T | Switch available tool |
| P | Cast fishing rod while aiming at nearby water |
| F | Interact with villagers or a furnace |
| G | Farming actions / place furnace where applicable |
| E | Eat available food |
| F5 | Switch first-person / third-person camera |
| V | Cycle the four player color palettes |
| F6 | Save world |
| ESC | Pause menu |
| F10 | Exit |

## World saves

World data is stored separately from player inventory and progression sidecar files. Keep the whole save folder together when making backups. Do not delete sidecar files if you want to preserve inventory, farm growth, or achievements.

## Notes

- The world format is documented in the project changelog; the current profile keeps format 2.
- Existing worlds are not automatically regenerated when you switch to a newer profile.
- Farm growth currently advances while the game is open; offline crop growth is not part of the documented 0.9.5 behavior.
- Back up important worlds before trying experimental mods.
