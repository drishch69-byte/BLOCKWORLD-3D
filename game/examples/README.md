# Примеры BLOCKWORLD 3D

- `bright-meadow-resource-pack.zip` — готовый ресурс-пак с настоящими PNG-текстурами 16×16. Импортируй его через меню «Ресурс-паки».
- `resource-pack-template/` — шаблон `pack.properties` и набор PNG в `textures/blocks/`. Можно заменить изображения своими.
- `mod-template/` — исходник простого Java-мода для предварительного API BlockWorld.

Текстуры: `textures/blocks/<block-id>.png`. Дополнительно поддерживаются `grass_top.png`, `grass_side.png`, `grass_bottom.png` и аналогичные варианты для других блоков.
